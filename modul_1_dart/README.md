# Modul 1: Bahasa Pemrograman Dart

Folder ini berisi implementasi materi dasar bahasa Dart sesuai Modul 1:
1. **Hello World**
2. **Tipe Data Fundamental** (`int`, `double`, `String`, `bool`, `var`)
3. **Operasi Matematika dan Logika**
4. **Struktur Kontrol** (`if-else`, `for`, `while`)
5. **Fungsi (Functions)**
6. **Pemrograman Berorientasi Objek (OOP)**
7. **Import Pustaka** (`dart:math`)
8. **Penanganan Eksepsi** (`try`, `on`, `catch`)
9. **Asinkronus** (`async` & `await`)

### Cara Menjalankan
```bash
cd modul_1_dart
dart run bin/main.dart
```
